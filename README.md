# PredictIT

Projeto de portfólio em Data Science voltado à predição de falhas em infraestrutura de TI nas próximas 1 a 3 horas com base em métricas operacionais.

## Projeto Publicado

O conteúdo principal do repositório está em:

- [predictit-failure-prediction/predict_IT.ipynb](predictit-failure-prediction/predict_IT.ipynb)
- [predictit-failure-prediction/executive_report.md](predictit-failure-prediction/executive_report.md)
- [predictit-failure-prediction/README.md](predictit-failure-prediction/README.md)

## O Que o Notebook Entrega

- Geração de dados simulados;
- Limpeza e preparação de dados;
- Análise exploratória com gráficos;
- Modelagem preditiva com diferentes abordagens;
- Análise de rede com PageRank;
- Conclusões executivas e próximos passos.

## Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras
- NetworkX
